# 잇테이블 가짜문 검증 — 런칭 콘텐츠 킷 (복붙용)

> 목적: 선결제 수용률 검증 트래픽 모으기. **생각 없이 복붙만** 하면 되게 만든 2주치 콘텐츠.
> 랜딩 URL — 오마카세(예약금): `eattable.kr/try?store=omakase-seocho` / 한우(코스선주문): `eattable.kr/try?store=hanwoo-gangnam`
> ⚠️ 봇·자동 스팸 금지(검증 오염). 진짜 사람 반응만이 데이터다.

---

## 0. 측정 규칙 (먼저 읽기)
- 채널마다 **다른 URL 파라미터**를 쓰면 어디서 온 트래픽인지 구분됨 → 끝에 `&src=threads` / `&src=danggn` / `&src=everytime` 붙이기
  - 예: `eattable.kr/try?store=omakase-seocho&src=threads`
- 하루 1개씩, 같은 시간대(점심 11:30 / 저녁 6시 전후 — 배고플 때)
- 관리자 → 운영 → 퍼널 검증에서 매일 숫자 확인

## 6. 댓글·DM 대응 템플릿 (반응 오면 복붙)

```
맞아요, 그래서 전액이 아니라 예약금(3만원)만 거는 방식부터 테스트 중이에요.
이 금액도 부담되실까요? 솔직한 의견이 제일 큰 도움이에요 🙏
```

**"이거 실제 매장 어디예요?"**
```
지금은 서비스 수요를 보는 단계라 오픈 전이에요!
신청해두시면 1호점 확정되는 즉시 가장 먼저 알려드릴게요 😊
```

**"노쇼 때문에 사장님들 좋아하겠다"**
```
정확해요! 고객은 웨이팅 제로, 사장님은 노쇼 제로 — 양쪽 다 이득이라
지금 사장님들도 같이 모으고 있어요. 혹시 아는 사장님 계시면 소개 환영이에요 🙌
```

```
감사해요! 출시 1순위로 모실게요. 주변에 예약 맛집 좋아하는 분 있으면 공유 부탁드려요 🙏
```

## 7. 점주 콜드 컨택 (선결제 문화 업종부터)

> 대상: 오마카세·한우코스·파인다이닝(이미 예약금/노쇼에 민감). DM/방문.

```
안녕하세요 사장님, 노쇼 없는 선결제 예약 서비스를 준비 중인 잇테이블입니다.

고객이 방문 전에 메뉴·결제까지 끝내고 오기 때문에
- 노쇼 0
- 피크타임 주방 몰림 완화 (도착 시간·메뉴를 미리 앎)
효과가 있습니다.

초기 파트너 매장은 수수료 0원으로 한 달 같이 테스트하고 있어요.
10분만 설명드려도 될까요?
```

---

### 운영 팁
- 같은 글 **여러 번 복붙 금지**(스팸 처리). 앵글을 바꿔가며.
- 반응 **0이어도 그게 데이터** — 3~5개 올려보고 클릭/댓글이 전혀 없으면 메시지를 바꿔서 재시도(업종·카피 variant).
- "선결제 부담" 댓글 수 ÷ 전체 반응 = 정성적 수용성 지표. 메모해두기.
